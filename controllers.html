03 / Control & instrumentation

Control the vehicle.
Measure the caster.

Wheel speed and turret heading close the motion loop. Independent encoders reveal how each supporting caster moves along the route.

01 / Motion architecture

Two loops, one trajectory.

The Raspberry Pi corrects position and heading. The drive ESP tracks wheel speeds and returns encoder and IMU measurements.

  1. Generate the reference

    Blend waypoint corners and schedule a feasible velocity through each segment.

  2. Correct the motion

    Combine reference velocity with position and heading feedback, then apply inverse kinematics.

  3. Track actuator rates

    Send wheel and turret commands to the ESP; return motion measurements to the Pi.

02 / Powered wheels

A speed loop
for each wheel.

Quadrature encoders measure how fast the left and right wheels turn. The ESP compares these rates with their targets and adjusts motor PWM.

u = uff + Kpe + Ki∫e dt + Kdde/dt

Feed-forward supplies the nominal effort; PID corrects the difference. Integral limits and output saturation keep the command bounded.

03 / Turret yaw

Keep the heading
while the base turns.

The Pi uses the turret's relative encoder angle and base orientation to estimate world heading. Its yaw correction coordinates turret rotation with the drive wheels.

The command travels through /turret/cmd_vel to the ESP. Encoder feedback returns through /turret/encoder_ticks and /HAMR_turret/odom.

Controller implementation

In the ROS/UART firmware branch, turret rate is mapped to PWM with a deadband, static-friction compensation, and a slew limit. World-heading feedback closes on the Pi. A separate local angle-PID mode is also present in the firmware; its activation depends on the selected command mode.

04 / Ball caster measurement

Three angles describe the motion.

H1 and H2 measure hemisphere rotation. CENTER measures the common rod. Each rotating module has its own ESP32-C6, battery, and wireless link.

Hemisphere 1

H1 / φ₁

Quadrature counts capture the first shell's accumulated rotation and rate. An index pulse provides a separate reference event.

Hemisphere 2

H2 / φ₂

The same acquisition chain measures the second shell independently, revealing differences between the two contact motions.

Common rod

CENTER / α

A parity-checked absolute encoder measures single-turn rod angle. Continuous turns are reconstructed only when valid.

/caster_encoder/CENTER/joint_states

These three boards measure the passive caster. They do not drive its hemispheres or command the robot.
