02 / Off-road terrain

Beyond the flat floor.

Uneven support changes contact, chassis attitude, and tracking. Paired routes let us measure those effects without changing the reference.

Both runs complete this route. The ball configuration has slightly lower position RMS in this pair; broader conclusions need repeated tests across terrain and contact settings. These rigid surfaces do not model soil deformation.

03 / Disturbance & resistance

Measure the force behind the motion.

A wheelchair caster must swivel its fork into a new rolling direction. The split ball mechanism can accommodate changes through its shell motion; the experiment tests whether that reduces reorientation resistance and path deviation.

Apply the same timed lateral push at the same chassis point, then measure peak tracking error and recovery time. In a separate pull test, use a force gauge to measure the force needed to start and sustain motion.

Lower pull force and stronger disturbance rejection are separate measurements. Record both before drawing a performance conclusion.
